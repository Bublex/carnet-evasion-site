# Site de Carnet d’Évasion

Pages publiques de l’app iPhone Carnet d’Évasion, servies par GitHub Pages (branche `main`, dossier racine) :

- `index.html` : présentation et assistance (URL d’assistance de la fiche App Store : `https://bublex.github.io/carnet-evasion-site/#assistance`) ;
- `confidentialite/index.html` : politique de confidentialité (URL de la fiche : `https://bublex.github.io/carnet-evasion-site/confidentialite/`).

HTML statique, sans Jekyll (`.nojekyll`). Couleurs reprises de l’app (`src/theme.js` du dépôt `unlock-score`).
